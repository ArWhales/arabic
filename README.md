موقع تعليمي عربي للعملات الرقمية، جاهز للنشر على GitHub Pages.

## 📁 الملفات (ارفعها كلها في نفس المجلد الجذري للمستودع)

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `course.html` | مركز المسارات التعليمية (12 مسار) + مشغّل الدروس (الهيكل فقط) |
| `course.js` | **محرّك صفحة الدروس بالكامل**: الترجمة الفورية، الوسائط، الاختبارات، البطاقات التعليمية، المعاينة المجانية |
| `auth.html` | تسجيل الدخول / إنشاء حساب |
| `admin.html` | لوحة تحكم تجريبية |
| `education-trading.html` / `education-web3.html` / `education-security.html` | روابط تحويل قديمة (تحوّلك تلقائياً لمسارات `course.html` المقابلة) |
| `styles.css` | التصميم المشترك لكل الصفحات |
| `course-data.js` | بيانات كل المسارات والدروس (عربي + إنجليزي) والاختبارات والوسائط |
| `config.js` | إعدادات Supabase (مفعّل حالياً بوضع تجريبي) |

**مهم:** `course.html` يعتمد على `course.js` كملف خارجي منفصل — لازم يكونوا الاثنين موجودين بنفس المجلد.

## 🚀 النشر على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub، أو استخدم مستودعك الحالي.
2. ارفع **كل الملفات أعلاه** إلى جذر المستودع (وليس داخل مجلد فرعي)، إلا إذا كان اسم مستودعك ليس `username.github.io` — عندها إما:
   - انشرها من الجذر وافتحها عبر `https://username.github.io/repo-name/index.html`، أو
   - في إعدادات GitHub Pages اختر Branch: `main` و Folder: `/ (root)`.
3. من إعدادات المستودع: **Settings → Pages → Source → Deploy from a branch** → اختر `main` و `/root`.
4. بعد حفظ الإعدادات، انتظر دقيقة إلى دقيقتين، ثم افتح الرابط الذي يظهر أعلى صفحة Pages.
5. **مهم:** تأكد أن الرابط الذي تفتحه ينتهي بـ `/index.html` أو بدونه (GitHub Pages يعرض `index.html` تلقائياً كصفحة رئيسية للمجلد).

### أخطاء شائعة تمنع عمل الموقع على GitHub
- رفع الملفات داخل مجلد فرعي (مثل `arabic/`) دون أن يعكس ذلك في الروابط الداخلية.
- نسيان رفع أحد الملفات (خصوصاً `styles.css` أو `course-data.js`) — الموقع يعمل جزئياً بدونها لكن بدون تصميم أو بدون محتوى.
- تسمية الملفات بأحرف مختلفة عن الروابط داخل الكود (حساس لحالة الأحرف على خوادم Linux التي يستخدمها GitHub Pages).

- **اختبار قصير بنهاية كل درس** (105 اختبار، سؤال اختيار من متعدد لكل درس) لازم تجاوبه صح عشان يتحدد الدرس كمكتمل ✓.
- **معاينة مجانية**: أول درس من كل مسار مفتوح للزوار بدون تسجيل دخول؛ باقي الدروس والاختبارات تتطلب حساباً.
- **وسائط حقيقية**: فيديو تجريبي حقيقي (MDN CC0) ومعرض صور حقيقية (Picsum) قابل للتكبير (Lightbox) داخل دروس مختارة، موسومة بعلامة ArabicWhales.
- **بطاقات تعليمية قابلة للطي (Flashcards/Accordion)** للمفاهيم المركّبة.
- **شارات إنجاز 🏅** تظهر على بطاقة المسار في المركز الرئيسي عند إكماله 100%.
- **قائمة دروس جانبية قابلة للطي على الجوال** بزر مخصص، منفصلة عن قائمة التنقل العلوية.
- **تصميم متجاوب بالكامل**: قائمة هامبرغر على الجوال، هيدر لا يتداخل مع التيكر أو الأزرار على أي حجم شاشة.
- **اسم المستخدم**: يظهر بجانب 🐳 في الهيدر بعد تسجيل الدخول، ويختفي زرا "تسجيل الدخول" و"انضم الآن" تلقائياً.

## 🔧 لتفعيل قاعدة بيانات حقيقية (بدل الوضع التجريبي)

افتح `config.js` وضع بيانات مشروع [Supabase](https://supabase.com) مجاني:
```js
const SUPABASE_URL = "https://xxxxx.supabase.co";
const SUPABASE_ANON_KEY = "your-anon-public-key";
```
بمجرد حفظ الملف، يتفعّل تسجيل الدخول الحقيقي والتحقق من البريد الإلكتروني وحماية الدخول الصارمة تلقائياً في كل الصفحات دون أي تعديل إضافي.
